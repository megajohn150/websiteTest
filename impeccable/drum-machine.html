Four bars, every project

The same sequence runs every time.

  1. Listen

    A call, a brief, a fixed quote.

  2. Sketch

    Three directions on paper, one chosen.

  3. Build

    The system, tested on real things.

  4. Hand over

    Files, guidelines and a walkthrough.
